## 📁 Featured Projects

### W2A Intelligence — Smart Waste-to-Assets Allocation System

**An automated matching engine connecting municipal waste collection to recycling partners using AI-powered waste classification.**

This academic project (Dept. of CSE, Comilla University) solves the inefficiency in waste management by intelligently matching waste batches with recycling plants based on capacity, type, and location.

**Key Features**
- 3NF-normalized MySQL relational database schema
- SQL-driven allocation engine matching waste batches by live plant capacity
- Google Gemini Vision API integration for automatic waste photo classification
- Live GPS collection tracking and CO₂ offset reporting
- Interactive dashboard with real-time analytics

**Tech Stack:** `Next.js` `React` `Tailwind CSS` `MySQL` `Google Gemini Vision API`

**Links:** [Live Demo](https://w2-a-intelligence-phi.vercel.app) · [Source Code](https://github.com/shahed-hassan-fz-rabbi/W2A-Intelligence)

### Fable — Ebook Marketplace & Digital Library

**A multi-role ebook marketplace platform with secure authentication and Stripe payment integration.**

Fable is a full-featured digital library where readers can purchase ebooks, authors can publish and track sales, and admins manage the entire platform.

**Key Features**

- Stripe Checkout payment workflow with webhook handlers
- Personalized reader library with progress tracking and bookmarks
- Author sales analytics dashboard with real-time metrics
- Digital invoicing and automated order processing

**Tech Stack:** `Next.js` `React` `Node.js` `Express.js` `MongoDB` `Stripe API` `Better Auth`
